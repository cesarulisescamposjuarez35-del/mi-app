# Mi App React

## Descripción

Este proyecto fue creado utilizando React y tiene como objetivo poner en práctica el uso de React, Git, GitHub y GitHub Pages.

## Tecnologías utilizadas

* React
* JavaScript
* Node.js
* Git
* GitHub
* GitHub Pages

## Instalación

Para ejecutar el proyecto de forma local:

```bash
npm install
npm start
```

La aplicación se abrirá en:

```text
http://localhost:3000
```

## Publicación

La aplicación fue publicada utilizando GitHub Pages.

### Enlace de la aplicación

https://cesarulisescamposjuarez35-del.github.io/mi-app/

## Comandos utilizados

```bash
git init
git add .
git commit -m "Primer commit"
git branch -M main
gh repo create mi-app --public --source=. --remote=origin --push
npm install gh-pages --save-dev
npm run deploy
git push
```
